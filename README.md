# T3_code

Skills e registros para usar o [T3 Code](https://github.com/pingdotgg/t3code) remotamente pelo celular.

- `skills/t3-code-acesso-remoto/SKILL.md`: passo a passo reproduzível (T3 Connect, com alternativas Tailscale/LAN).
- `docs/registro-2026-11-12.md`: registro da configuração feita em 2026-11-12.

Para usar a skill no Claude Code, copie a pasta `skills/t3-code-acesso-remoto` para `~/.claude/skills/`.
