# Registro: T3 Code no celular (2026-11-12)

Objetivo: usar o T3 Code do PC (Windows 11) pelo celular Android, de qualquer rede.

## Linha do tempo

1. Pesquisa: README do T3 Code e guia oficial `docs/user/remote-access.md` listam 4 rotas (T3 Connect, Tailscale, LAN, SSH).
2. Escolha: **T3 Connect** (sem abrir porta no roteador).
3. PC: `winget install T3Tools.T3Code` → já instalado, atualizado para **0.1.9**.
4. Abertura do app: tela de logo por ~30 s antes de carregar (normal após atualização).
5. Settings → Sharing & access → T3 Connect → **Sign in** (login feito pelo usuário).
6. Resultado no PC: "Tunnel connected · 4 connections · QUIC", "1 of 3 tunnels in use".
7. Celular: app T3 Code, mesma conta. Em *Add environment*, seção "managed relay": host **Connected** (bolinha verde). Tocou ✓.
8. Teste: mensagem no Chats → agente respondeu. **Concluído.**

## Decisões e lições

- O relay gerenciado dispensa QR, endereço e código. O bloco "Address / Code" da tela *Add environment* é só para LAN/Tailscale.
- Suspensão do Windows derruba a conexão. O agente não mexe em configurações de energia; passou o comando `powercfg /change standby-timeout-ac 0` ao usuário (que depois informou já ter resolvido).
- A ferramenta de "manter acordado" do app do agente só vale durante a sessão, então não substitui a configuração do Windows.
- Login e app do celular são sempre do usuário.
